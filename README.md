# Tente Chess ♟️

A chess web app: play, solve puzzles, analyze with Stockfish, and train openings — all in the browser, no install needed.

## What's inside

- **Puzzles**: 2,869 real Lichess puzzles, offline, with hints, solutions, streak and rating
- **Analysis**: Stockfish engine analysis, best-move lines, and chess.com-style move classifications (Brilliant, Great, Best, mistakes and blunders)
- **Openings**: 3,704 named openings (ECO + name) with an openings trainer
- **Training**: guided endgame training, defense challenge, arrows and circles, coach tips
- **Tools**: PGN import, FEN board editor with engine analysis, automatic opening names, PNG export
- **Extras**: move sounds, clocks, themes, two-player on one screen

## Play

Open the GitHub Pages site for this repo (see the link on the repo's About section once Pages is enabled), or open `index.html` in any browser.
